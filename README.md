# cpp-oop-exercises

C++ Object-Oriented Programming practice programs — classes & objects, encapsulation, polymorphism, and Inheritance with real-world examples. Written during my BS Computer Science journey.

## Topics covered

- Classes & objects
- Constructors — including overloaded constructors
- Composition — a class used inside another class
- Encapsulation — private data with getters and setters
- Member functions

## Programs

| Program | What it shows | Files |
| --- | --- | --- |
| Invoice | A class with private data, a constructor, and getters/setters. Calculates the invoice amount with 20% VAT and a discount. | `Invoice/Invoice.h`, `Invoice/Invoice.cpp` |
| HealthProfile | A `healthProfile` class with a composed `DateofBirth` object inside it. Overloaded constructors (numeric month and month name), age from date of birth, BMI, and max / target heart-rate calculations. | `HealthProfile/healthProfile.h`, `HealthProfile/healthProfile.cpp` |

## How to run

Open a program's folder in VS Code and compile its `.cpp` file with g++, then run it.
